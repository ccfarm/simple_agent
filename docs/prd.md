# PRD：个人 A 股投研助手 MVP

## 1. 项目目标

构建一个A股投研助手，帮助用户维护关注股票列表，自动拉取指定股票的研究报告、新闻、公告等资料，并基于这些资料与 AI 进行问答分析。

## 2. 目标用户

个人 A 股投资者。

## 3. 核心场景

用户希望在本机维护自己的关注股票池，并针对某只股票快速获取最新公开资料，再通过 AI 基于这些资料进行问答，例如：

- 最近有哪些重要公告？
- 机构研报怎么看这家公司？
- 最近新闻是否有负面信息？
- 这家公司近期风险点有哪些？
- 帮我总结这只股票的最新投资逻辑。

## 4. MVP 功能范围

### 4.1 DeepSeek API Key 配置

用户可以在 Web 页面中配置 DeepSeek API Key。

功能要求：

- 支持填写、保存、修改 API Key
- API Key 保存在本机配置文件中
- 调用 AI 问答时使用该 Key

### 4.2 股票列表管理

用户可以维护个人关注股票列表。

功能要求：

- 新增股票
- 删除股票
- 修改股票信息
- 查看股票列表

股票基础字段：

| 字段 | 说明 |
|---|---|
| 股票代码 | 如 `600519` |
| 股票名称 | 如 `贵州茅台` |
| 市场 | SH / SZ / BJ |
| 备注 | 可选 |

### 4.3 指定股票资料拉取

用户可以选择某只股票，拉取最新公开资料。

资料类型：

- 研究报告
- 新闻
- 公司公告

功能要求：

- 支持按股票触发资料拉取
- 拉取结果保存到本机指定文件夹
- 每只股票单独建文件夹
- 文件按资料类型分类保存

示例目录：

```text
data/
  stocks/
    600519_贵州茅台/
      reports/
      news/
      announcements/
```

### 4.4 本地资料管理

系统展示已下载资料列表。

功能要求：

- 查看某只股票已下载的资料
- 按类型区分：研报 / 新闻 / 公告
- 支持打开本地文件路径
- 支持重新拉取最新资料

### 4.5 资料向量索引

系统对已下载资料建立向量索引，为 AI 问答提供语义检索能力。

触发时机：用户在「拉取 / 重新拉取」资料时，资料落地（写入 `.md` 文件并落库）后自动对新增资料建立/更新索引，作为拉取动作的后续步骤完成，用户无需额外操作。

功能要求：

- 在拉取流程完成资料落地后，对本次新增的资料（Markdown）按语义切分为片段（chunk）
- 通过本地 embedding 模型（HuggingFace / BGE）将片段向量化
- 使用 LlamaIndex 构建向量索引并本地持久化，片段携带元信息（股票、资料类型、来源文件、原文链接）
- 仅对新增资料增量入库（已索引的资料跳过，避免重复）
- 索引过程复用拉取的异步流程，进度与结果随拉取一并反馈
- 支持按问题做语义检索，返回最相关的片段及其来源资料

### 4.6 AI 问答

用户可以选择某只股票，基于已下载资料与 AI 对话。

功能要求：

- 用户输入问题
- 系统通过 LlamaIndex ChatEngine（CondensePlusContext 模式）复用 4.5 建立的同一索引，自动完成检索召回、多轮历史压缩与 query 改写
- 将召回片段作为上下文
- 调用 DeepSeek API（经 LlamaIndex OpenAILike LLM 封装）返回回答
- 回答中标注引用到的本地资料文件（来自检索结果的来源节点）
- 支持连续提问，由 ChatEngine 维护多轮上下文

示例问题：

```text
请总结这家公司最近一个月的主要利好和风险。
```

```text
根据最新公告，这家公司有什么重大变化？
```

### 4.7 多用户与注册登录

系统支持多个用户各自独立使用，数据按用户隔离。

功能要求：

- 开放注册：任何人可用用户名 + 密码注册账号（流程尽量精简，仅用户名、密码两项）
- 登录 / 退出：注册后用用户名 + 密码登录，登录态由服务端会话（session cookie）维护
- 密码安全：密码加盐哈希存储，不存明文
- 数据隔离：每个用户拥有独立的股票列表、资料、向量索引与设置（含各自的 DeepSeek API Key）
- 访问控制：除注册 / 登录页外，所有页面与 API 需登录后才能访问；用户只能访问自己的数据
- 不迁移历史数据：上线多用户后，原单用户库内的存量数据不做归属迁移（以全新隔离结构启用）

> 隔离粒度：`stocks` / `documents` / `settings`（含 API Key）均按 `user_id` 隔离；本地资料与向量索引文件按用户目录分区存放。

### 4.8 云端部署

系统支持部署到一台云主机，供用户通过浏览器随时访问。采用轻量方式部署，不引入容器编排。

功能要求：

- 轻量部署：在云主机上用 Python 虚拟环境安装依赖，uvicorn 常驻运行（可用 systemd 守护、开机自启）
- 数据持久化：SQLite 数据库文件、资料文件、向量索引文件均存放在主机磁盘目录，进程 / 主机重启不丢数据
- 配置外置：会话密钥（`APP_SECRET_KEY`）等敏感配置通过环境变量配置，不硬编码
- 可访问性：服务监听 HTTP 端口，可直接访问，或配合反向代理（如 Nginx）对外提供服务

> 数据库与存储：沿用 SQLite + 本机磁盘方案（适合个人 / 中小规模）；后续如需更高并发可平滑迁移到 PostgreSQL 与对象存储（见第 11 节）。

## 5. 非 MVP 功能

以下功能暂不做：

- 自动交易
- 投资建议推送
- 实时行情
- 复杂量化回测
- 手机端适配
- 数据可视化大屏

## 6. 技术栈

选择原则：常见、简单、本机部署友好。

### 推荐技术栈

| 模块 | 技术 |
|---|---|
| 后端 | Python + FastAPI |
| 前端 | HTML + JavaScript + Bootstrap |
| 数据存储 | SQLite |
| 本地文件存储 | 本机文件夹 |
| AI 接入 | DeepSeek API（经 LlamaIndex OpenAILike 封装，ChatEngine 编排） |
| 资料抓取 | Python requests / BeautifulSoup |
| PDF / 文档解析 | PyMuPDF / pymupdf4llm（解析为 Markdown） |
| RAG 框架 | LlamaIndex（切分、索引、检索、问答编排） |
| 向量存储 | LlamaIndex 自带向量存储，本地持久化 |
| 文本向量化 | 本地 embedding 模型（HuggingFace sentence-transformers / BGE） |
| 用户认证 | 用户名 + 密码（加盐哈希，passlib/hashlib），服务端 session cookie |
| 服务启动 | uvicorn |
| 部署方式 | 本机运行 / 云主机 uvicorn 常驻（可选 systemd 守护 + Nginx 反代） |

### 技术选择说明

- **FastAPI**：适合快速开发本机 Web 服务和 API。
- **SQLite**：无需单独安装数据库，适合单人本机使用。
- **HTML + JavaScript + Bootstrap**：避免前端工程复杂度，快速做出可用页面。
- **本地文件夹存储**：方便用户直接查看和备份资料。
- **pymupdf4llm**：将研报/公告 PDF 解析为带标题层级与表格的 Markdown，利于资料切分与检索。
- **LlamaIndex**：统一封装切分、向量化、索引、检索与 LLM 问答；资料索引（M6）与 AI 问答（M7）复用同一套索引对象与代码，减少重复实现；检索结果自带来源节点，便于标注引用资料。
- **LlamaIndex 自带向量存储**：本地持久化、零额外服务，适合本机单人 RAG 场景；后续数据量增大可平滑切换到 Chroma 等向量后端。
- **本地 embedding 模型**：使用 HuggingFace sentence-transformers（默认 `BAAI/bge-small-zh-v1.5`，约 100MB、CPU 友好、中文效果好），向量化完全在本机离线运行，不依赖云端 embedding 服务、无需额外 API Key；模型首次使用自动下载并缓存。
- **用户认证（session cookie）**：相比 JWT 更简单直观，服务端维护会话即可；密码加盐哈希存储，登录态写入签名 cookie，满足"尽量精简"的多用户诉求。
- **轻量云端部署**：直接在云主机上用虚拟环境运行 uvicorn（可配 systemd 守护），数据库 / 资料 / 索引落在主机磁盘目录；相比容器化更省心、依赖更少，适合个人自用规模。

## 7. 系统结构

```text
浏览器 Web 页面（注册 / 登录）
      ↓ session cookie
FastAPI 后端（认证中间件 → 按 user_id 路由数据）
      ↓                  ↘
SQLite 数据库          LlamaIndex 向量索引（按用户目录持久化）
(users/stocks/         ↑
 documents/settings)   │
      ↓                  │
本地资料文件夹（按用户分区）─→ 切分 + 本地 embedding
      ↓
DeepSeek API（用各用户自己的 API Key，基于检索片段问答）

[ 云端部署：以上整体在云主机用 uvicorn 常驻运行，数据库 / 资料 / 索引存放在主机磁盘目录 ]
```

## 8. 页面规划

> 除注册页与登录页外，以下页面均需登录后访问；页面顶部展示当前登录用户名与「退出」入口。

### 8.0 注册 / 登录页

功能：

- 注册：填写用户名 + 密码完成注册
- 登录：用户名 + 密码登录，成功后进入股票列表页
- 退出：清除会话并返回登录页

### 8.1 设置页

功能：

- 配置 DeepSeek API Key
- 配置资料保存根目录

> 资料向量化使用内置的本地 embedding 模型（`BAAI/bge-small-zh-v1.5`），无需在设置页配置。

### 8.2 股票列表页

功能：

- 查看股票列表
- 新增股票
- 编辑股票
- 删除股票
- 选择股票进入详情页

### 8.3 股票详情页

功能：

- 查看股票基础信息
- 一键拉取资料
- 查看已下载资料
- 进入 AI 问答

### 8.4 AI 问答页

功能：

- 显示/切换当前股票
- 输入问题
- 展示 AI 回答
- 展示引用到的本地资料文件名

## 9. 数据模型

> 多用户隔离：`stocks` / `documents` / `settings` 均新增 `user_id` 外键，所有查询按当前登录用户过滤。

### 9.0 用户表 users

| 字段 | 类型 | 说明 |
|---|---|---|
| id | integer | 主键 |
| username | text | 用户名（唯一） |
| password_hash | text | 加盐哈希后的密码 |
| created_at | datetime | 注册时间 |

### 9.1 股票表 stocks

| 字段 | 类型 | 说明 |
|---|---|---|
| id | integer | 主键 |
| user_id | integer | 所属用户 ID |
| code | text | 股票代码 |
| name | text | 股票名称 |
| market | text | 市场 |
| note | text | 备注 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 9.2 资料表 documents

| 字段 | 类型 | 说明 |
|---|---|---|
| id | integer | 主键 |
| user_id | integer | 所属用户 ID |
| stock_id | integer | 股票 ID |
| doc_type | text | report / news / announcement |
| title | text | 标题 |
| source | text | 来源 |
| url | text | 原始链接 |
| file_path | text | 本地路径 |
| published_at | datetime | 发布时间 |
| created_at | datetime | 下载时间 |

### 9.3 配置表 settings

| 字段 | 类型 | 说明 |
|---|---|---|
| user_id | integer | 所属用户 ID（与 key 组成联合主键） |
| key | text | 配置项 |
| value | text | 配置值 |

### 9.4 向量索引 LlamaIndex

资料片段由 LlamaIndex 构建为向量索引并本地持久化，每个节点（node）包含：

| 字段 | 说明 |
|---|---|
| node_id | 片段唯一标识 |
| text | 片段文本内容（Markdown） |
| embedding | 片段向量（本地 embedding 模型生成） |
| metadata | 元信息：股票 ID、资料类型、来源文件路径、原文链接、发布时间 |

## 10. MVP 验收标准

- 可以在本机启动 Web 服务
- 可以配置 DeepSeek API Key（资料向量化使用内置本地 embedding 模型，无需配置）
- 可以新增、编辑、删除股票
- 可以选择某只股票并拉取研报、新闻、公告
- 拉取资料能保存到本机指定文件夹
- 可以查看已下载资料
- 已下载资料能建立向量索引并支持语义检索
- 可以基于某只股票的本地资料向 AI 提问
- AI 回答中能说明参考了哪些本地资料
- 可以用用户名 + 密码注册、登录、退出；未登录无法访问业务页面与接口
- 不同用户的股票、资料、索引与设置（含 API Key）相互隔离，互不可见
- 可以部署到云主机用 uvicorn 常驻运行，数据库 / 资料 / 索引存放在主机磁盘，进程 / 主机重启后数据不丢

## 11. 后续迭代方向

- 支持更多资料来源与资料类型
- 支持可选的云端 embedding / 更大的本地模型以提升检索效果
- 高并发场景下从 SQLite 平滑迁移到 PostgreSQL，资料与索引文件迁移到对象存储（S3 / OSS）
- 更完善的账户体系（找回密码、邮箱验证、邀请码 / 管理员审批、权限角色）
- 资料增量更新策略优化（按发布时间/版本去重与重建索引）
