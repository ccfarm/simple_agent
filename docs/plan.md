# 开发计划：个人 A 股投资助手 MVP

按里程碑推进，每个里程碑完成后打勾验证。

## [x] M1 项目骨架与服务启动
- 初始化 Python 项目（FastAPI、uvicorn、SQLite 等依赖）
- 搭建 FastAPI 基础服务与 Bootstrap 前端布局、导航（设置页、股票列表页、股票详情页、AI 问答页）
- 验证：本机启动服务后浏览器可访问页面并在导航间切换

## [x] M2 数据层与配置管理
- 建立 SQLite 数据库与 stocks / documents / settings 三张表
- 实现设置页：保存/修改 DeepSeek API Key 与资料根目录
- 验证：自动建表成功，配置保存后重启仍可读取

## [x] M3 股票列表管理
- 实现股票增删改查（代码、名称、市场、备注）
- 股票列表页与详情页打通
- 验证：页面新增/编辑/删除实时正确更新，可进入详情页

## [x] M4 资料拉取与本地存储
- 按股票拉取研报/新闻/公告并写入 documents 表
- 按 `data/stocks/代码_名称/{reports,news,announcements}` 分类保存
- 文档解析（PyMuPDF / pdfplumber）提取正文文本
- 验证：磁盘生成正确目录结构，资料可解析出可读文本

## [x] M5 本地资料管理
- 详情页按类型展示已下载资料，支持打开本地文件与重新拉取
- 验证：资料按研报/新闻/公告分组展示，可定位本地文件并刷新

## [x] M6 向量索引与资料检索
- 引入 LlamaIndex 作为 RAG 框架，对已下载资料（Markdown）做切分、向量化并构建本地持久化索引
- 索引在「拉取 / 重新拉取」资料落地后自动触发（复用异步流程），仅对新增资料增量入库
- 通过本地 embedding 模型（HuggingFace / BGE）生成向量，完全离线运行
- 验证：拉取后自动建立向量索引，按问题做语义检索返回相关片段与来源文件

## [x] M7 AI 问答
- 复用 M6 的 LlamaIndex 索引，用 ChatEngine（CondensePlusContext 模式）串起检索召回、多轮上下文压缩与问答，接入 DeepSeek API（经 OpenAILike LLM 封装）
- 回答中标注引用的本地资料文件名（来自检索结果来源节点）
- 验证：多轮问答正常，回答标注引用资料，PRD 第 10 节验收逐条通过

## [x] M8 多用户与注册登录
- 新增 users 表与认证模块（用户名 + 密码，加盐哈希），实现注册 / 登录 / 退出与 session cookie 登录态
- 增加认证中间件 / 依赖：除注册登录页外所有页面与 API 需登录访问
- stocks / documents / settings 增加 user_id，数据访问层全部按当前用户过滤；资料与索引文件按用户目录分区
- 各用户独立配置 DeepSeek API Key；存量历史数据不做归属迁移
- 验证：两个账号注册登录后，股票 / 资料 / 索引 / 设置互相隔离不可见，未登录被拦截到登录页
